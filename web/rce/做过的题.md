## 踩坑汇总

1. **先确认回显方式**：有回显 → 直接读；无回显 → 时间盲/外带/写文件，别死磕回显。
2. **先定 shell 类型**：Linux 用 `;`，Windows 用 `&`，用错了会以为"没有命令注入"。
3. **`flag` 被拦就想通配符**：`/f*`、`/fla?`、`[f]lag` 这三招能解决大部分关键字过滤。
4. **空格被拦用 `${IFS}`**：注意 `$IFS$9` 更稳，因为 `$IFS` 后紧跟字符可能被当成变量名的一部分。
5. **外带前先确认出网**：目标可能禁外网，先用 DNSLog 确认（DNS 常比 HTTP 更容易出去）。
6. **base64 外带要删换行**：`| base64 | tr -d '\n'`，否则 URL 会被换行截断。
7. **PHP `disable_functions` 绕过要具体分析**：`LD_PRELOAD`、`putenv`、`imap_open` 等各有前提，别硬套。
8. **写文件路径要确认可写**：`/tmp`、Web 目录、`/dev/shm` 常可写；先 `ls -ld 目录` 看权限。
