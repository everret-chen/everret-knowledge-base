# Web 方向总览

> 本目录按**考点**分文件夹，每个考点固定三个文件，写法统一，方便检索和复用。

## 三件套约定

| 文件 | 写什么 | 判断标准 |
| --- | --- | --- |
| `原理笔记.md` | 漏洞产生的**根因**、触发条件、数据库/语言差异、检测思路、防御与绕过 | 能不看资料给别人讲明白「为什么会漏」 |
| `payload.md` | 可直接复制的**验证 payload**，按场景分类成表 | 比赛时能直接搜出来用，不用重新想 |
| `做过的题.md` | 做过的题目记录：考点、关键步骤、卡在哪、结论 | 三个月后重看能想起当时怎么做的 |

> 新增考点：复制任意一个现成考点目录的结构，改名字，然后在下面的进度表登记一行。
