## 踩坑汇总

1. **先定上下文再写 payload**：直接扔 `<script>alert(1)</script>` 没反应，多半是落在属性里或 JS 字符串里，需要先闭合。
2. **看 Elements 而不是 View Source**：DOM 型里 payload 可能已经被 JS 解析过一轮，响应源码看不出来。
3. **长度限制**：被截断时用短 payload（`<svg onload=alert(1)>`）或把代码放到 `window.name` / `location.hash`。
4. **Cookie 读不到**：检查 `HttpOnly`，改为"以受害者身份发请求"的思路。
5. **打 BOT 的坑**：确认 BOT 访问的是哪个页面、Cookie 作用域对不对；外带域名要能被 BOT 访问到（内网地址可能不通）。
6. **CSP 报了错但 payload 没执行**：F12 Console 会明确告诉你违反了哪条策略，按策略提示找白名单域。
