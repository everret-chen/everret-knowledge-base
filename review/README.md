## 为什么要写复盘（写给未来的自己）

比赛当时的思路、踩的坑、时间怎么花的，**过一周就会忘掉 80%**。而这些恰恰是最有价值的部分：

- **做出来的题**：记下"突破口"——是看到什么信息才想到这个方向的。这才是可迁移的能力。
- **没做出来的题**：记下"卡在哪"——下次遇到同类题就知道该往哪想。
- **时间分配**：记下时间都花在哪些题上、什么时候该果断放弃。这比多会一个 payload 更能提升排名。

## 沉淀去向

复盘里发现的可复用内容，要**顺手挪到对应考点**，否则下次还是找不到：

| 复盘里发现的东西 | 挪到哪 |
| --- | --- |
| 好用的 payload | `web/<考点>/payload.md` |
| 新的原理理解 | `web/<考点>/原理笔记.md` |
| 某类题的固定套路 | `web/<考点>/原理笔记.md` 或 `misc/README.md` |
| 常用的脚本/命令 | 对应考点的 `payload.md` 里存代码块 |
